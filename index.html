GitHub Pages Anleitung

Arnes-Game-Welt läuft komplett auf jedem Smartphone, Tablet oder Laptop ohne Server!

  1. Erstelle ein Repository auf GitHub.com.
  2. Füge den Code in eine Datei namens index.html ein.
  3. Gehe zu Settings → Pages und wähle den Branch main.
  4. Fertig! Arnes-Game-Welt ist sofort online erreichbar!
